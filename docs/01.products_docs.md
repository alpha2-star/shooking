# 상품 목록 페이지 프로젝트

## 프로젝트 개요
이 프로젝트는 사용자가 다양한 상품을 한눈에 확인하고, 관심 있는 상품을 클릭하여 장바구니에 담을 수 있도록 구현된 웹 애플리케이션입니다. 사용자 친화적인 인터페이스와 빠른 상품 탐색이 핵심 목표이며, 기본적인 쇼핑 흐름을 경험할 수 있도록 구성되었습니다.
참여인원: dlgh0123


## 개발 환경

프레임워크: React (v17.0)

언어: JavaScript (ES6+)

스타일링: styled-components

상태 관리: Redux Toolkit

의존성 관리: npm

## 설치 및 실행 방법

cd your-project
npm install
npm start

## 컴포넌트 구조

ProductList: 전체 상품 목록을 화면에 출력하는 컴포넌트

ProductCard: 개별 상품 정보를 카드 형태로 보여줌
