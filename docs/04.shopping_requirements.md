## 📝 고객 요구사항 정리
1.쇼핑몰 페이지 연동

기존에 각각 따로 존재하던 페이지들을 자연스럽게 연결

사용자 경험을 해치지 않고 매끄럽게 이동 가능해야 함

2.데이터 일관성 유지

페이지 간 이동 시에도 데이터 상태가 유지되어야 함

예: 상품 목록에서 장바구니에 담은 상품이 메인 페이지에서도 동일하게 반영

3.상세 페이지 추가

상품별 상세 정보 페이지 구현

장바구니 및 메인 페이지와 연동

4.테스트 URL 제공

개발 진행 중 테스트용 URL을 제공하여 고객 측에서 직접 리뷰 가능하도록 함

5.디자인 반영

디자인은 영업팀이 별도로 제공 예정

전달된 디자인 가이드를 바탕으로 UI/UX 구현

6.일정

개발 예상 기간: 약 2주

중간 점검을 통해 필요 시 일정 조율
## 📋 기능 목록
1.페이지 연동 기능

메인 페이지 ↔ 상품 목록 페이지 ↔ 장바구니 페이지 간 원활한 이동

각 페이지 이동 시 데이터 동기화

2.상품 데이터 상태 관리 기능

전역 상태 관리 도입 (예: Redux, Context API 등)

상품 담기/삭제 시 전체 페이지에 동일하게 반영

3.상세 페이지 기능

상품별 상세 정보 조회 가능

상세 페이지에서 장바구니 담기 기능 지원

4.테스트 환경 제공 기능

테스트용 URL 배포

중간 리뷰 가능하도록 반영

5.디자인 적용 기능

전달받은 디자인 시안 반영

사용자 친화적인 UI/UX 제공
